# 流程自动化助手 FlowPilot

一款 Chrome 浏览器扩展（Manifest V3），用于**记录网页操作流程并全自动执行**。

核心机制：每一步执行后会等待页面的"反应"（出现指定文字 / 出现指定元素 / 网址变化），

- 反应按预期出现 → 执行该反应配置的"对应选择"（可选），继续下一步；
- **未等到预期反应 → 终止本轮执行，自动从第一步重跑整个流程**（重跑次数可配置，防止死循环）。

---

## 一、安装（开发者模式加载）

1. 打开 Chrome，地址栏输入 `chrome://extensions/` 回车；
2. 打开右上角的 **开发者模式** 开关；
3. 点击左上角 **加载已解压的扩展程序**，选择本插件文件夹（`flowpilot`）；
4. 工具栏出现插件图标即安装成功。建议点图钉固定到工具栏。

> Edge 浏览器同样适用：`edge://extensions/` → 开发者模式 → 加载解压缩的扩展。

## 二、快速上手（三步）

### 第 1 步：录制流程

1. 打开目标网站，点击插件图标 → **开始录制新流程**；
2. 像平常一样在页面上操作：点击按钮、填写输入框、选择下拉/单选/复选；
3. 操作完成后再次打开插件弹窗，输入流程名称，点 **完成并保存**。

录制内容会自动生成步骤列表（点击 / 输入），并自动为每步生成多个候选元素选择器。

### 第 2 步：补充反应规则（关键）

录制的步骤默认"执行完直接下一步"。要实现"针对每一步的反应做出相对应选择"，需要补充反应规则：

1. 插件弹窗 → **打开编辑器**（或右键插件图标 → 选项）；
2. 选中流程 → 点击某一步的 **编辑**；
3. 在 **反应规则** 区域点 **+ 添加反应**，配置三样东西：
   - **如果页面**：出现文字 / 出现元素 / 网址包含 —— 填匹配内容；
   - **则**：不做动作直接下一步 / 点击某元素 / 输入内容 —— 即"对应选择"。
4. **保存流程**。

示例：点击"提交"按钮这一步，加两条反应规则——

| 如果页面 | 匹配值 | 则 | 对应选择 |
|---------|--------|----|---------|
| 出现文字 | 提交成功 | 不做动作 | （直接下一步） |
| 出现文字 | 验证码错误 | 点击元素 | text=刷新验证码 |

### 第 3 步：运行

1. 打开目标网站（建议停在流程起始页）；
2. 插件弹窗 → 对应流程卡片点 **▶ 运行**；
3. 插件自动逐步执行；弹窗实时显示进度、每步日志、重跑次数；
4. 任一步未等到预期反应 → 本轮终止，**自动从第一步重跑**；超过重跑上限（默认 3 次）后停止并提示。

## 三、反应监测的三种类型

| 类型 | 含义 | 匹配值写法 |
|------|------|-----------|
| 出现文字 | 页面可见文字包含指定内容 | 如 `提交成功`、`审核不通过` |
| 出现元素 | 页面出现指定元素 | CSS 选择器如 `#okBtn`，或 `text=确定` |
| 网址包含 | 当前网址包含指定内容 | 如 `/pay/success` |

## 四、选择器说明

每一步通过"选择器"定位页面元素，支持三种写法（每行一个，按顺序尝试，第一个找到的生效）：

- `#id` —— 元素 id，如 `#username`；
- 任意 CSS 选择器 —— 如 `form button[type=submit]`、`.login-panel input[name=pwd]`；
- `text=文字` —— 按可见文字模糊匹配按钮/链接等可点击元素，如 `text=登录`。

录制时插件会自动生成主选择器 + 备选选择器；若网站改版导致执行找不到元素，可在编辑器中手动调整。

## 五、导入 / 导出

- 弹窗和编辑器均支持**导出 JSON**（单流程备份、分享）；
- **导入 JSON** 支持单个流程对象或流程数组。

## 六、文件结构

```
flowpilot/
├── manifest.json        插件清单（MV3）
├── background.js        执行引擎：步骤调度、反应等待、超时从头重跑
├── content.js           页面层：录制操作、执行点击/输入、监测反应
├── popup/               插件弹窗：录制控制、流程列表、运行状态
├── options/             流程编辑器：步骤增删改、反应规则配置
└── icons/               图标
```

## 七、常见问题

- **为什么某步总是失败重跑？** 多为选择器失效（页面改版）或反应匹配值写错，打开弹窗看日志定位到具体步骤，在编辑器中修正。
- **页面跳转后还能继续吗？** 能。引擎会等待新页面加载完成后继续监测与执行（整页跳转和单页应用内部跳转都支持）。
- **重跑次数想改多/改少？** 编辑器顶部"超时后从第一步重跑次数上限"，0 表示失败后直接停止不重跑。
- **哪些页面不能录制/执行？** 浏览器自身页面（设置页、应用商店等）出于安全限制无法注入脚本。
- **数据存在哪？** 全部保存在浏览器本地（chrome.storage），不上传任何服务器。
